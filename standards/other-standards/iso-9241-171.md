# ISO 9241-171 — Software Accessibility Overview

ISO 9241-171 is an ergonomics standard focused on the accessibility of software user interfaces. It is useful when a task goes beyond web content conformance and into broader software UI behavior, preferences, input/output flexibility, and assistive technology compatibility.

**Important limitation:** The full ISO text is not freely available. This file is a curated overview and routing guide, not a mirror of the standard.

---

## What ISO 9241-171 Covers

The standard is used for software accessibility topics such as:

- keyboard access and focus behavior
- text presentation and readability
- user preferences and personalization
- input and output alternatives
- error handling and feedback
- interoperability with assistive technologies
- documentation and help content
- timing, interruptions, and user control

It is especially relevant to desktop software, line-of-business applications, kiosk software shells, and other non-web software interfaces.

## When to Use This Standard

Use ISO 9241-171 guidance when the question is:

- about desktop or enterprise software rather than a website
- about accessibility settings and user preferences
- about software ergonomics, not just success-criterion conformance
- about designing robust accessible controls, dialogs, navigation, and feedback

---

## Practical Engineering Themes

### Input Flexibility

Software should support keyboard and alternative-input operation without requiring precise pointer use or time-critical interaction.

### Output Flexibility

Text, status, and feedback should be available in forms users can perceive, including compatibility with screen readers, magnifiers, and other assistive technology.

### User Control and Preferences

Accessible software should respect or expose settings for text size, contrast, sound, timing, and input behavior where practical.

### Predictable Interaction

Users benefit when controls, focus movement, command behavior, and feedback are consistent throughout the software.
