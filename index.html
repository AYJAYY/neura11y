How to use it

A simple flow is enough. The repo does the heavy lifting after you hand the right files to the model.

1

Download the repository

Put it in the same workspace, folder, or project context your AI tool can access.

2

Feed the routing files first

Start by giving the AI AI-USAGE-GUIDE.md and INDEX.md.

3

Add a small task bundle

Add only the files for your task instead of dumping the whole repo into a single prompt.

4

Review the result

Treat the AI output as assisted draft work. Check important claims, thresholds, and details.

Pick a task bundle

Use these as starting sets. They match the repo that is present now and keep the AI focused on the job you actually want done.

Web

Build or audit a page or component

  • AI-USAGE-GUIDE.md and INDEX.md
  • standards/wcag/wcag-2.2-quick-ref.md
  • standards/aria/wai-aria-1.2-roles.md
  • standards/aria/aria-authoring-practices.md
  • domains/web/ files for your exact task
Documents

Create an accessible document

  • AI-USAGE-GUIDE.md and INDEX.md
  • ai-prompts/documents/accessible-document.md
  • domains/documents/ guide for Word, PDF, PowerPoint, Excel, or plain language
  • standards/pdf-ua/pdf-ua-overview.md when PDF rules matter
Social

Write an accessible social post

  • AI-USAGE-GUIDE.md and INDEX.md
  • ai-prompts/social-media/accessible-social-post.md
  • domains/social-media/alt-text/alt-text-principles.md
  • domains/social-media/captions-and-transcripts/caption-guide.md
  • domains/social-media/platforms/ guide for the platform you are using
Compliance

  • legal-and-compliance/ files for region-specific context

What is in the repo now

The repo is no longer just a few setup files. It now spans the standards layer, applied guidance, templates, and supporting reference material.

Standards

Normative source material

WCAG, ARIA, Section 508, PDF/UA, EPUB, EN 301 549, ATAG, and related files under standards/.

Domains

Applied guidance

Web, documents, and social media guidance under domains/, including components and testing.

Prompts

Starter templates

Use the prompt files in ai-prompts/ when you want the AI to start from a known framing.

Support

Extra context

Legal, media, screen reader, cognitive, color, reference, and repo-maintenance material round out the pack.

Example prompt

If you want a plain starting prompt, use something like this after attaching the files for your task.

Starter prompt

Short and direct

I attached files from an accessibility repository.
Use only those files as source material.
If the files do not fully cover the request, say that clearly.
Help me create or review accessible [page / component / document / social post].
