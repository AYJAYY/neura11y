# Creating Accessible PDF from InDesign

InDesign can produce tagged PDFs, but only if structure and export settings are prepared carefully.

---

## InDesign Preparation

- Use paragraph styles consistently for headings and body text
- Use article/story flow and reading order intentionally
- Add alt text and export metadata for images
- Use real lists and real tables where possible
- Avoid using design-only layout tricks as substitutes for structure

---

## Export Checklist

1. Export as Adobe PDF (Interactive or Print, depending on workflow)
2. Enable tagged PDF output
3. Preserve hyperlinks and bookmarks where relevant
4. Include document metadata

---

## Post-Export Verification

Always verify the PDF in Acrobat:

- heading tags
- logical reading order
- figure alt text
- table structure
- language and title metadata

InDesign export is a starting point, not proof of PDF/UA conformance.
