# Excel Accessibility Checklist

Use this as the short-form spreadsheet review list.

---

## Structure

- [ ] Data ranges are formatted as tables
- [ ] Column headers are unique and descriptive
- [ ] Merged cells are avoided for layout
- [ ] Blank rows and columns are not used for spacing
- [ ] Worksheet tabs have descriptive names

## Content

- [ ] Charts and images have alt text
- [ ] Color is not the only cue
- [ ] Hyperlinks are descriptive
- [ ] Text contrast is sufficient

## Validation and Output

- [ ] Named ranges are used where helpful for large sheets
- [ ] Accessibility Checker shows no errors
- [ ] If exported to PDF, tags and reading order are verified afterward
