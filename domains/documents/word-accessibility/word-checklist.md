# Microsoft Word Accessibility Checklist

Use this as the short-form audit list. For workflow detail, pair with `domains/documents/word-accessibility/word-guide.md`.

---

## Structure

- [ ] Use built-in heading styles, not manual bold/large text
- [ ] Keep heading hierarchy sequential
- [ ] Use built-in bulleted and numbered lists
- [ ] Avoid text boxes for core content

## Images and Tables

- [ ] All meaningful images have alt text
- [ ] Decorative images are marked decorative
- [ ] Tables use a real header row
- [ ] Tables are simple and avoid layout-only merged cells

## Text and Links

- [ ] Link text is descriptive
- [ ] Language is set correctly
- [ ] Contrast is sufficient and color is not the only cue

## Export and Validation

- [ ] Document title is set in file properties
- [ ] Images use "In Line with Text" wrapping where possible
- [ ] Accessibility Checker shows no errors
- [ ] PDF export keeps "Document structure tags for accessibility" enabled
