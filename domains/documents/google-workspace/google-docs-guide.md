# Google Docs Accessibility Guide

## Structure

- Use built-in heading styles for document structure
- Use normal paragraph text for body copy
- Do not fake headings with larger font size or bold text only
- Keep heading levels sequential

## Lists and Tables

- Use built-in bulleted and numbered lists
- Use simple tables with a single header row
- Avoid merged cells where a simpler table can work
- Add short text before the table explaining what users should notice

## Images and Links

- Add alt text to meaningful images
- Mark decorative images as decorative when the workflow supports it, or remove them from the content flow
- Use descriptive link text instead of pasted raw URLs where possible

## Collaboration Risks

- Comments and suggestions can interrupt reading order for assistive technology users
- Resolve outdated comments before distribution
- Confirm that shared documents use the correct language setting and title

## Export and Distribution

- Re-check accessibility after exporting to PDF, Word, or EPUB
- Verify heading structure, links, and image alt text survived export
- If sharing as PDF, review tags and reading order separately
