# Google Slides Accessibility Guide

## Slide Basics

- Give every slide a unique title
- Use built-in slide layouts instead of placing everything manually
- Keep one main idea per slide
- Use short bullets and strong contrast

## Reading Order

- Check the object order for title, body, charts, and footnotes
- Place supporting objects after the main message
- Avoid floating decorative elements that interrupt the content order

## Visuals

- Add alt text to charts, images, and diagrams
- If a chart is complex, summarize the key finding in visible slide text or speaker notes
- Do not rely on color alone to separate data series

## Presenting and Sharing

- Speaker notes can carry longer explanations and transcript-ready text
- If exporting to PDF or PowerPoint, re-check accessibility in the destination format
- Share a companion text outline when the deck is dense or data-heavy
