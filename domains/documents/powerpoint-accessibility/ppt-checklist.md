# PowerPoint Accessibility Checklist

Use this as the short-form review list. For workflow detail, pair with `domains/documents/powerpoint-accessibility/powerpoint-guide.md`.

---

## Slide Structure

- [ ] Every slide has a unique, descriptive title
- [ ] Built-in slide layouts are used instead of manually placed text boxes where possible
- [ ] Reading order in the Selection Pane is logical

## Content

- [ ] All meaningful images, charts, and SmartArt have alt text
- [ ] Decorative images are marked decorative
- [ ] Tables are simple and use a header row
- [ ] Links are descriptive
- [ ] Color is not the only cue
- [ ] Text contrast meets 4.5:1 for body text and 3:1 for large text

## Media and Export

- [ ] Video has captions
- [ ] Audio has a transcript
- [ ] Speaker notes cover complex visuals where needed
- [ ] Accessibility Checker shows no errors
- [ ] PDF export keeps document structure tags enabled
