# TikTok Accessibility Guide

**IMPORTANT:** TikTok's accessibility features are evolving rapidly, particularly captioning tools. Verify current capabilities before providing guidance. Last verified: 2026-03-13.

---

## Video Captions

### Auto-Generated Captions

TikTok provides automatic captions for videos. Auto-captions are generated using speech recognition.

**Enabling auto-captions during upload:**
1. After recording or uploading a video
2. On the Post screen, tap "Captions"
3. TikTok generates captions automatically
4. Review the captions by tapping on caption text to edit
5. Post with captions enabled

**Editing auto-captions:**
1. On the captions review screen, scroll through all caption blocks
2. Tap any incorrect word to edit it
3. Correct errors and save

### Manual Caption Editing

TikTok allows editing individual caption blocks on the auto-generated text. There is no SRT file upload option as of 2026 (unlike YouTube or Twitter/X).

**Workaround for custom captions:** Burn captions into the video using a video editing app (CapCut, Adobe Premiere, etc.) before uploading to TikTok.

### Auto-Caption Default Behavior

TikTok's auto-captions display as text overlaid on the video. Viewers can:
- Toggle captions on/off (Settings → Accessibility → Auto-captions)
- Caption display depends on the viewer's captioning settings

**Important:** If you enable captions on your video, they are visible by default to viewers who have auto-captions enabled in their settings. Some viewers may not see them unless this setting is on.

## Image Alt Text

TikTok is primarily a video platform. For photo posts (TikTok Photo Mode):
- No native alt text support for TikTok photo posts as of 2026
- Include image descriptions in the post caption text as a workaround

## Accessible Video Production Practices

Since TikTok is video-first, the following in-video accessibility practices apply:

### Captions in Video

- **On-screen text captions** — Add captions directly in TikTok's caption editor or pre-burned
- **High contrast** — Caption text needs 4.5:1 contrast against the video background
- **Caption placement** — Default is center-bottom; avoid placing over important visual content
- **Font size** — Ensure captions are legible on mobile screens; TikTok's default size is generally appropriate

### Audio and Sound Design

- **Voiceover narration** — Describe what is happening visually when relevant
- **Sound effects** — If a sound effect is integral to the message, describe it in captions
- **Music** — If content meaning depends on the song or lyrics, include lyric captions
- **Trending sounds** — Describe the audio content in the caption if the sound is part of the message

### Text On Screen

- Use TikTok's built-in text tool for readable text overlays
- Use high-contrast color combinations (white on dark, dark on light)
- Keep text on screen long enough to be read at average reading speed: 150-200 words per minute = ~4-5 seconds for a short phrase
- Avoid text that appears only for 1-2 seconds

### Visual Content

- Describe key visual elements in the voiceover or spoken content when possible
- For product demonstrations: name the product and describe what you're doing
- For instructional content: provide audio description of steps alongside visual demonstration

## TikTok Post Text and Description

### Caption Text (Post Description)

- Up to 4,000 characters
- Include a description of the video content for context
- Add image/video description for static visual content

### Hashtags

- CamelCase: #AccessibilityTok not #accessibilitytok
- TikTok hashtags are important for discovery (FYP algorithm)
- 3-8 relevant hashtags is typical practice
- Popular accessibility hashtag: #DisabilityTok #AccessibilityTok #A11y

## Text-to-Speech Feature

TikTok offers a built-in text-to-speech (TTS) voice that reads on-screen text aloud. This can benefit users who have difficulty reading small text.

- Add on-screen text in the text editor
- Tap the text; select "Text-to-speech"
- Choose a voice
- TTS voice reads the text at the appropriate timestamp

**Accessibility consideration:** TTS reads the on-screen text, which helps hearing users who cannot read the text. However, this is not the same as audio description for visual content.

---

## Audio Description on TikTok

No native audio description feature exists on TikTok as of 2026.

**Workarounds:**
- Narrate visual content as part of the main audio ("I'm now showing a close-up of the product's back panel, which has a USB-C port")
- Post a separate video with embedded audio description
- Include a detailed description in the post caption

## TikTok Accessibility Settings

**Settings → Accessibility:**
- **Auto-captions** — Enable/disable captions on all videos
- **Large text** — Increase text size in the app
- **Animated thumbnails** — Enable/disable animated preview thumbnails (reduces motion)
- **Bold text** — Enable bold font weight

---

## TikTok for Business / Creator Accessibility

For business accounts and creators publishing accessible content:
1. Always enable and review auto-captions before posting
2. Use CapCut (TikTok's editing app) to add high-quality captions before upload
3. Narrate visual content in your voiceover
4. Include descriptive post captions
5. Use CamelCase hashtags for all multi-word tags

---

## Known Accessibility Issues (as of 2026)

- **No SRT upload** — Cannot import professional caption files
- **No photo alt text** — Photo posts lack alt text support
- **Live streams** — No live captioning for TikTok LIVE
- **Duets/Stitches** — Original video's captions may not carry through to duet
- **Effects and filters** — No accessibility information about visual effects applied
- **FYP algorithm** — Does not factor accessibility features into content distribution
- **Comments** — Limited screen reader support for scrolling and reading comments
