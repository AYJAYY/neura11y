# Alt Text by Image Type

The best alt text depends on what kind of image it is and what job the image is doing in the post.

---

## Quick Reference

| Image Type | Alt Text Strategy |
|------------|-------------------|
| Simple object | Name the object and the relevant visible detail |
| Person or people | Describe the action, context, and relevant appearance details |
| Text screenshot | Transcribe the visible text or summarize with a pointer to full text |
| Chart or graph | State the chart type and the main takeaway |
| Infographic | Lead with the main message, then key points |
| Meme | Explain the image format and the joke or contrast |
| Product photo | Describe the product, visible features, and context |
| Logo | Name the organization and describe the design briefly if needed |
| Before/after | Label both states clearly |

---

## Examples

### Text Screenshot

`Tweet from @accessibility_news: "Latest WCAG update officially published with 9 new success criteria."`

### Chart

`Bar chart showing Q4 revenue led by North America at $4.2M, followed by Europe at $2.9M and APAC at $0.8M.`

### Meme

`SpongeBob mocking meme with text contrasting a serious accessibility request and a dismissive response.`

### Product Photo

`Matte black wireless headphones with padded ear cups on a wooden desk beside a laptop.`

---

## Reminder

The same image can need different alt text in different posts. Context decides what is important.
